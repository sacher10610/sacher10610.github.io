# 通常開始と専用再挑戦の分離（2026-10-21）

ユーザーの追加指定により、1周目到達後も「はじめから」は通常周回とし、「もう一度、あの日から」で開始した周回だけトゥルー系分岐を利用できるよう変更。

## 現在の条件

| キー | 用途 |
| --- | --- |
| `sf.true_bad_seen` | 全セーブ共通の初回ED到達記録。専用再挑戦ボタンの表示条件として維持する |
| `f.march_retry_run` | 各セーブの専用再挑戦周回フラグ。「はじめから」で必ずfalse、初回ED到達後の専用ボタンでのみtrueにする |

4月の追加選択肢と追加会話への直接入口、3月の帰還前分岐・最後の選択肢・TRUE入口・通常ENDから最後の選択肢へ戻るボタンには、**両方のキーが厳密にtrue**という条件を適用。TRUE音楽を開始するJavaScript側でも同じ条件を確認する。

初回ED到達記録を得ただけでは、その周回の `f.march_retry_run` は有効にしない。通常のBAD経験によるLEARNED、記録・CGの回収状態、全記録リセットの既存動作は変更しない。

## セーブの扱い

新しいフラグはTyranoの通常のゲーム変数 `f` に置き、各セーブの状態として保持。別の周回を「はじめから」で開始しても、保存済みの専用再挑戦周回のフラグは変えない。変更前のセーブやキーが未定義のセーブは通常周回扱いとし、初回ED到達記録から自動で専用周回へ昇格させない。

トゥルーへ向かう周回は、更新後に「もう一度、あの日から」から開始する。

## 変更・確認

変更は `title_screen.ks`、`n04_april.ks`、`n03_march.ks`、`march_ending.js` の4ファイル。ブラウザ版・TyranoBuilder作業版へ同じ内容を反映。既存ラベルのコマンド位置・行位置は維持。

実エンジンのパーサー／隔離VMで以下を確認。画面操作、ユーザーの実セーブの読込・書込、試聴は実行していない。

- 通常開始時に以前の専用周回フラグを必ず解除し、専用開始時だけ有効化。両方とも名前入力へ進み、全体の到達記録を保持。
- 通常開始・専用開始・旧セーブでの4月の実際の選択肢集合と、追加会話の直接入口を確認。4月・3月の分岐条件60ケースを確認。
- 初回到達済みでも通常周回では初回EDルートとなり、専用周回では通常END1・2とTRUEへ到達。通常周回のED到達で専用周回フラグが勝手に有効化されない。
- TRUE実行タグは未定義・false・文字列・数値の周回フラグを拒否。セーブ状態を模した独立したJSON往復でも通常・専用の区別を保持。
