# 原本検査・プリロードの注意

1. `ASSET_MANIFEST.csv` / `ASSET_MANIFEST.json` のファイル名・サイズ・SHA256で**同梱原本の整合性**を確認。`VERIFY_ASSETS.py`も使用可。
2. 全新規PNGは**1672×941**（約16:9）。ゲーム画面比率16:9に収め、強引な非等方伸張を避ける。必要ならアスペクトを維持してトリミング／軽微な黒帯を扱う。ユーザー画像原本は変更しない。
3. 暫定MP4は1280×720、30fps H.264、AAC。TyranoBuilder実環境で全画面再生・音声内蔵・再生終了検知をチェック。
4. `366日目のレシピ.mp3`は273.240秒。『本物のパティシエ』は202.512秒。コーデック読み込み・音量・BGM重複を検証。
5. 動画と高解像度CGを読み込む前に現在のキャラ・CGの表示レイヤーを整理。画面遷移中の白／黒フラッシュを最小限にする。
6. ムービー再生に失敗してもゲームを停止させないが、通常テストで不具合を隠蔽しない。ログに理由を残す。
7. 旧月の共通SEや日常背景・キャラクター立ち絵は既存プロジェクトに存在すると想定し、二重登録／再圧縮しない。存在しないものはそのまま報告し、勝手な別キャラを捏造しない。
