# 表示・入力・音のライフタイム管理

- **背景3枚**：scene転換前に不要レイヤーを片付け、BG15_01→02→03。大会後は夜のKomorebi背景へ。タイトル復帰時に大会のキャラやCGを残さない。
- **CG15_01〜04**：決まったシーンのみ、イベントCG表示→本文規定タイミングで通常背景に復帰。次場面へのCG残留禁止。
- **CG15_05**：帰還直前まで。その後の動画へはイベントCG・立ち絵を隠し、黒画面や前景残りを作らない。
- **動画**：開始時は通常BGM停止。音声内蔵。endedで動画レイヤー破棄→真BADエピローグ。閉じ忘れや二重endedイベント禁止。
- **CG15_06**：無音の朝厨房・人物ゼロ。TRUE名呼びCGと誤って解放しない。
- **CG15_07/08**：TRUE曲全体で手動進行できない。シナリオ中での表示タイミングに応じて解放。過去のCGが上に残らない。
- **ENDCARD_TRUE_01_FIN**：画面全体（実画像にfin＋右下意匠＋ロゴがすでに焼き込まれている）。UI、セリフ、ボタン画像、カーソル表示案内、選択肢、メッセージ枠、スタッフロールなし。内部の全画面決定領域は必要最小限。
- **TRUEカード入力**：`cardShown && waitElapsed && musicEnded` の全成立後に1回だけ受付。楽曲が終わってもユーザーが操作しなければ画面を維持。入力でタイトルへ移った瞬間にTRUEロックとキー監視を解除。
- **DEBUG確認モーダル**：記録画面より前面。取消／実行後にレイヤーを破棄。既存スクロール位置とタブを破壊しない。
- **セーブ復帰**：TRUEの自動進行中を途中復旧するより、FINAL③の安全な前チェックポイントから再開する。音源と画面のズレを許さない。
