- 音量設定（ユーザーCONFIG）は尊重する。ゲーム内強制100%設定や多重BGMは禁止。
- 映像に**音声が入っている**ことは確認済み。`二人で歩んだ軌跡(レシピ).mp3`は `assets/audio/reference_only`に同梱するが、現在の再生経路では使用しない。
- 動画終了後は**ムービー完了イベント**から遷移し、227秒固定タイマーを使わない。後日別尺動画へ置き換えるため。
- 366曲再生中、ユーザー操作で途中の画面を進めない。手動スキップ禁止・通常AUTO解除禁止。
- 音声が読み込めない時はスキップ解放して済ませない。ユーザーにリトライ選択や安全な再生回復方法を提示するが、できる限りUIをコンセプトに合わせる。
