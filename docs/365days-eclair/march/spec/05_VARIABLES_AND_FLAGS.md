# 状態管理・永続フラグ

| 論理名 | ストレージ | 初期 | 書き込み契機 | 用途 |
|---|---|---|---|---|
| `sf.true_bad_seen` | 永続 `sf` | false/未定義 | 真BAD017カード**到達時**にtrue | 2周目4月INSIGHT／タイトル再挑戦／3月最終三択の**唯一の解除判定** |
| 3月MINI BAD012既読 | 既存の失敗記録方式に合わせる | 未回収 | MINI BAD012表示時 | 選択肢への再試行・記録 |
| 3月MINI BAD013既読 | 同上 | 未回収 | MINI BAD013表示時 | 同上 |
| CORE BAD017既読/記録 | 既存のBAD記録方式に合わせる | 未回収 | 真BADカード到達 | 『失敗の記録』への追加。`sf.true_bad_seen`と同期 |
| 3月クリア | 既存月間CLEAR方式 | false | 総合1位達成ルートで適切に更新 | 月進行・世界一実績 |
| `sf.true_end_seen` **相当** | 既存変数があれば再利用 | false | TRUE終了時 | 記録・閲覧用。TRUE解放の条件に使わない |
| TRUE ED自動進行中 | **非永続** | false | ③押下〜finカード終了 | 入力封鎖・復旧を制御。`sf`にしない |
| TRUE音楽完奏 | **非永続** | false | 音声終了イベント | finカードの入力許可AND条件 |
| finカード後ウェイト経過 | **非永続** | false | カード表示から約1500ms | finカードの入力許可AND条件 |
| 一周目動画再生中 | **非永続** | false | 再生開始〜動画終了 | 重複起動防止、音声制御 |

- 変数の**実名は既存TyranoBuilderプロジェクトで照合**する。論理名だけで新規に重複作成しない。
- 旧セーブから `sf.true_bad_seen` が未定義でも false 扱い。**変数初期化で既存trueを上書きしない**。
- 一般プレイの初期化は `sf.true_bad_seen` を消さない。デバッグボタン押下時だけ**明示的に false にする**。
- 初回での世界一・動画再生のタイミングでは `true_bad_seen` をtrueにしない。カードを見て到達確定した瞬間。
- 2周目の4月INSIGHT選択の既読フラグ、他のBAD数、好感度をTRUE解放条件へ追加しない。
- タイトルの「もう一度、あの日から」を押しても、過去の記録・CG・セーブはクリアしない。
- DEBUGボタンは `sf.true_bad_seen` **だけ**をfalseに戻す。過去の記録やCG開放フラグやTRUE到達フラグは残す（意図的）。開発中だけの機能。
- 非永続のED操作禁止フラグはタイトル復帰後に解除。セーブからの復帰でロック状態が残らないこと。
