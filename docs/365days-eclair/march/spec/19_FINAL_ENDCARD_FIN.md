# TRUE終幕・fin画像の正式採用

**本パックに同梱済み：** `assets/ui/ENDCARD_TRUE_01_FIN.png`

この一枚を**完成静止画像**として使用する。画像はすでに**黒背景／中央fin／右下のサークル風ロゴと年号・関連の既存風表記**が成立したユーザー採用版。白背景・グラデーション・人物・クレジットを足さない。タイトルの文字装飾を別途重ねない。

### 切替条件
1. TRUE ED内、固定最終文「**世界一になった次の日も、店は朝から仕込みだった。**」を**音楽継続中**に表示。
2. 読了時間の後、フェードで `ENDCARD_TRUE_01_FIN.png` の全画面へ。テキスト枠・HUD・ボタン画像を全て隠す。
3. 表示してから**約1.5秒間は入力無効**。
4. **『366日目のレシピ』が完奏**したかも別条件で待つ。曲が先に終わっても1.5秒経過を待ち、1.5秒が先でも曲の完奏を待つ。
5. 両条件達成後にEnter／決定／クリック／タップを1回受け付け、タイトルへ。勝手には戻らない。操作案内文字は出さない。
6. タイトル復帰時にTRUE用の操作封鎖／音声監視を完全解除。エンドカードの残留禁止。

### 旧仕様との差分
- **TRUEのスタッフロールは廃止**。1周目に用いる専用の見せかけED**ムービー**とは別で、混同しない。
- fin画像に新しいコピーを重ねたり、ゲーム内タイトル文字を自動出力しない。
- 画像内の「2026〜」等の表記は**採用された画像のとおり**。再生成や文字修正を独断で行わない。
