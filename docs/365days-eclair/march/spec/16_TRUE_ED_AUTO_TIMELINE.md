# TRUE ED 音楽同期・自動進行・入力制御

## 入口と不変条件
- `FINAL CHOICE③「抹茶ちゃんが決めればいい」` **決定イベントの直後**、`One Year, One Eclair` を止めて **『366日目のレシピ』を先頭から**。曲は273.240秒、ノンループ、1回のみ。
- この選択以後は**手動クリック送り／Enter／スキップ／AUTO解除による停止を封鎖**。台詞・トランジション・CGを自動進行。ボタンやクリック待ちを残さない。
- 女神と抹茶の対話、初名前呼び、本人の「ウチ、帰らへん」、女神の退場、4月1日の厨房、固定最終文は**全部同一曲の中**で進む。
- **専用TRUEムービーなし、スタッフロールなし。**

## finカード操作条件（厳格）
`cardVisible && elapsedSinceCardShown >= 1500ms && musicEnded` がすべてtrueになった場合だけ、**Enter／決定／クリック／タップ**の入力を解放。それまでは押下しても何もしない。
- **曲が終わっても自動遷移させない**。カードは入力があるまで表示。
- 入力1回につきタイトル遷移1回。ダブルクリック二重起動を防止。
- 説明文・「CLICK TO CONTINUE」・フッター・スタッフロールを表示しない。
- TRUE到達フラグを既存方式で保存。操作ロック・イベントリスナーを確実に解除しタイトルの正常操作を復元。

## セーブ・エラー
- TRUE楽曲の途中からのロードで音ズレ／無音放置にならないよう、**最終選択直前のチェックポイントから再開**する設計を推奨。ED中セーブは禁止または正規復帰処理を導入。
- 再生不可環境でスキップを解放するのは禁止。安全な音声再試行・エラー復帰を用意する。
- ユーザーのBGM音量設定を尊重。曲の強制音量変更なし。
- `sf.true_bad_seen` がTRUEでない場合にこの音源が誤再生されないよう試験。
