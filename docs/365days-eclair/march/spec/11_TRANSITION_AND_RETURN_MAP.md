# 復帰先・イベント終了の条件

| 入口 | 通過 | 復帰先 | 要注意 |
|---|---|---|---|
| 2月CLEAR | MARCHアイキャッチ | 3月SCENE01 | 二重ジングル防止 |
| CHOICE00 A/B | MINI012/013 | **CHOICE00** | ゲームオーバーにせず再選択 |
| CHOICE01 A/B | REVIEW A/B | **CHOICE01** | 新BADとして登録しない |
| 3月共通SCENE10 | `sf.true_bad_seen=false` | 11A | 選択肢を出さない |
| 11A | CG15_05、暫定ED動画 | **12A** | 動画 ended イベントで自動遷移、曲二重不可 |
| 12A | CG15_06／無音の真BAD017 | **タイトル** | カード到達でsf更新、2周目ボタン表示 |
| 3月共通SCENE10 | `sf.true_bad_seen=true` | 11B | 三択へ |
| FINAL①/② | それぞれ通常END | タイトル／既存ED復帰 | TRUE曲・TRUEカード使用禁止 |
| FINAL③ | TRUE全編→finカード | **操作入力でタイトル** | 音源完奏＋約1.5秒。自動復帰なし |
| 記録→DEBUG reset | 確認モーダル→永続書換 | 記録画面、タイトル再表示 | 既存記録を消さず、古い解放表示を最新化 |

**共通：** 背景・キャラ・一時UIレイヤー、オート／スキップロック、BGMが他シーンへ漏れないこと。既存プロジェクトの安全なtitle-return macroを再利用する。
