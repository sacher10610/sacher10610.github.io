# 初回ED・暫定ムービー 実装と置換仕様

## 今回は動画あり
- 同梱：`assets/video/march_first_ending_temp.mp4`
- **3:47.133**（227.133s）、**1280×720、30fps、H.264映像、AAC音声あり**。外部MP3を同時に重ねない。
- ゲーム内固定参照パス例：`data/video/march_first_ending.mp4`。**temp**という名前のファイルでも、シナリオから参照する名前を一定にする。既存実装の動画パス規約があればそれに合わせる。
- **後日同じ参照パスのファイルを正式版へ置換するだけ**で済む構造。尺固定のタイマーは絶対使わない。

## 正式な呼び出し順
1. 3月SCENE11A、抹茶ちゃんの瞬間帰還・CG15_05終了。
2. `One Year, One Eclair`をフェードアウト／停止。
3. 前景・選択肢・メッセージUIを隠してムービー再生。**ムービーAAC音声のみ**を鳴らす。
4. 動画終了（**ended**）で動画レイヤーを閉じ、音声を停止し、無音を確保。
5. 必ずSCENE12Aへ。真BADエピローグの静けさを残す。**ムービーの終了をゲーム完了と誤認してタイトルへ戻さない**。
6. 真BAD017カード到達まで `sf.true_bad_seen` は false のまま。

## 異常時
- 動画欠品・非対応・読み込み失敗・権限で再生不可になったら、無限待ちせず、再生リトライかログ付き安全遷移で**SCENE12Aを必ず到達可能**にする。失敗した動画を「視聴済み成功」と誤記録しない。
- ユーザーが途中でアプリを閉じた場合、保存済みの直前ポイントから安全に再生可能にする。
- 動画の音量挙動はゲームのConfig BGM設定と整合させる。BGM重複、動画無音、二重endedハンドラに注意。
- 正式版の映像と音声方式が変わる場合のみ施工仕様を更新する。現時点の暫定映像に追加編集・文字焼込みは要求しない。

## 検証
通常1周目、既読真BADをデバッグボタンで解除してから再周回、ロード経由、動画音声／BGM重複、動画正常終了、動画欠品テストをすべて検証。
