# TRUE BAD後の再挑戦・4月INSIGHT・タイトル導線

1. `sf.true_bad_seen` の**真偽のみ**がTRUE解放のトリガー。初回は未定義／false扱い。
2. 1周目で真BAD017カード到達→フラグtrue。タイトルを再描画したとき**「もう一度、あの日から」**が出る。既存のSTART/CONTINUE/RECORD/CONFIG/EXITとデザイン・hoverを合わせる。
3. 再挑戦ボタンを押すと正規の4月開始処理を呼ぶ。`sf`を初期化しない。既存の初回説明やプロローグの扱いは既存プロジェクト構造に合わせ、突然3月へワープしない。
4. 4月の初期Choiceへ `INSIGHT｜「……君は、本当に帰りたいの？」` を**真BAD後に追加**。既存選択肢・BAD・CLEAR・共通マクロに干渉しない。INSIGHTの会話は `docs/03_SCENARIO_CONFIRMED.md` 付録Aを採用。終了後は4月の正規導線へ復帰。
5. そのINSIGHTを読まずにロード等から3月へ来た場合も、`sf.true_bad_seen=true` なら最後の三択へ到達できる。**4月INSIGHT閲覧済みフラグを別条件にしない**。
6. DEBUGボタンで `sf.true_bad_seen=false` にしたら、タイトルの再挑戦ボタンは消え、3月SCENE10分岐は初回へ戻る。旧記録とCGは残ってよい。
7. タイトル画面へ戻る前にCG・キャラの前景・ムービー・エンドカード・音声・入力封鎖を確実に片付ける。メニューの旧ページ状態や二重ボタンを残さない。
